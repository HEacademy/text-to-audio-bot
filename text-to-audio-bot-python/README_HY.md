# Telegram Text-to-Audio Bot (Python)

Այս բոտը քո ուղարկած տեքստը ElevenLabs API-ով դարձնում է MP3 խոսք և ուղարկում քեզ կամ քո ընտրած Telegram օգտատիրոջը։ Միայն քո Telegram ID-ն կարող է ստեղծել/ուղարկել աուդիո։ Ստացողը նախ պետք է բացի բոտը և սեղմի Start։ Բոտը սովորական հեռախոսազանգ չի կատարում։

## Ինչ է պետք

- Python 3.10 կամ ավելի նոր տարբերակ
- Telegram բոտի token՝ ստացիր Telegram-ի `@BotFather`-ից (`/newbot`)
- ElevenLabs API key և Voice ID
- Ինտերնետ կապ

## Windows-ում գործարկում

1. ZIP-ը բացիր մի թղթապանակում։
2. Ներբեռնիր և տեղադրիր Python 3.13-ի Windows 64-bit տարբերակը [python.org-ից](https://www.python.org/downloads/windows/)։ Եթե տեղադրիչը ցույց տա **Add Python to PATH** տարբերակը, միացրու այն։ Տեղադրումից հետո փակի՛ր ու նորից բացի՛ր Command Prompt-ը։
3. Կրկնակի սեղմիր `install_windows.bat`։ Եթե Python-ը դեռ տեղադրված չէ, ֆայլը հիմա հստակ կասի՝ որտեղից տեղադրել այն։
4. Նույն պանակում պատճենիր `.env.example` ֆայլը և պատճենի անունը փոխիր `.env`։ Եթե Windows-ը ֆայլի ընդլայնումը թաքցնում է, համոզվիր, որ անունը վերջանում է `.env`, ոչ թե `.env.txt`։
5. `.env` ֆայլում լրացրու՝
   - `TELEGRAM_BOT_TOKEN` — BotFather-ի token-ը
   - `ELEVENLABS_API_KEY` — ElevenLabs API key-ը
   - `ELEVENLABS_VOICE_ID` — ElevenLabs-ի ընտրած ձայնի ID-ն
6. Քո Telegram ID-ն գտիր՝ բացելով [@userinfobot](https://t.me/userinfobot) և սեղմելով Start։
7. Այդ թիվը տեղադրիր `.env`-ի `ALLOWED_TELEGRAM_USER_IDS=` տողում։ Սա է բոտի տիրոջ միակ թույլատրված ID-ն։
8. Պահպանիր `.env`-ը և գործարկիր `run_windows.bat`։ Telegram-ում բոտին ուղարկիր `/start`, հետո՝ `/id`՝ ստուգելու համար։
9. Ստացողին խնդրիր գտնել քո բոտը, բացել և սեղմել Start։ Նա պետք է ունենա Telegram username։
10. Քո բոտին գրիր `/to @username`՝ ընտրելու ստացողին։ Դրանից հետո ուղարկած յուրաքանչյուր տեքստի ձայնը կուղարկվի նրան։ Քեզ ուղարկելու համար գրիր `/to off`։

## Ստացող ընտրել

- Միայն `ALLOWED_TELEGRAM_USER_IDS`-ում նշված տերը կարող է ուղարկել տեքստ և ստեղծել աուդիո։ Մյուսները կարող են միայն սեղմել Start՝ որպես ստացող գրանցվելու համար։
- Ստացողը պետք է նախ գրի բոտին `/start` և ունենա Telegram username։ Telegram-ի բոտերը չեն կարող առաջինը սկսել անձնական զրույց օգտատիրոջ հետ։
- Տերը գրում է `/to @username`։ Մինչև `/to off` հրամանը նոր տեքստերի աուդիոները կուղարկվեն ընտրված օգտատիրոջը։
- Ստացողը չգտնվելու դեպքում խնդրիր նրան կրկին սեղմել Start։ Գրանցված օգտատերերի username/chat ID զույգերը պահվում են `recipients.json` ֆայլում։

## Python հրամաններով գործարկում

Թղթապանակի ներսում բացիր Terminal կամ PowerShell և գործարկիր՝

```bash
python -m venv .venv
```

Windows-ում ակտիվացրու միջավայրը՝

```powershell
.venv\Scripts\Activate.ps1
```

Տեղադրիր կախվածությունները և գործարկիր՝

```bash
pip install -r requirements.txt
python bot.py
```

Նախքան գործարկումը լրացրու `.env` ֆայլը։

## GitHub և Cloudflare

- GitHub-ը կարող է պահել նախագծի կոդը։ **`.env` ֆայլը մի վերբեռնիր GitHub**․ `.gitignore`-ն այն բաց է թողնում։
- Այս տարբերակը սովորական Python ծրագիր է և աշխատում է polling-ով։ Cloudflare Workers-ը դրա համար պետք չէ։
- Եթե բոտը գործարկես քո համակարգչում, այն կաշխատի միայն մինչ համակարգիչն ու բոտի պատուհանը միացված են։ Մշտական աշխատանքի համար պետք է Python ծրագիր գործարկող հոսթինգ։

## Խնդիրների արագ ստուգում

- `Բացակայում են .env կարգավորումները` — լրացրու նշված արժեքները։
- Telegram-ից պատասխան չկա — ստուգիր token-ը և համոզվիր, որ `run_windows.bat`-ի պատուհանը բաց է։
- ElevenLabs-ի սխալ — ստուգիր API key-ը, Voice ID-ն, հաշվի քվոտան և մոդելի հասանելիությունը։
- Հայերեն արտասանությունը — Voice ID-ն փոխիր հայերենին համապատասխանող ձայնով։

## Անվտանգություն

- Երբեք մի ուղարկիր bot token-ը կամ ElevenLabs API key-ը ուրիշներին և մի տեղադրիր դրանք հանրային repository-ում։
- Սկզբնական կարգավորմամբ բոտից կարող է օգտվել միայն այն Telegram ID-ն, որը նշված է `.env`-ի `ALLOWED_TELEGRAM_USER_IDS` դաշտում։
- API-ների օգտագործումը կարող է ծախսել ElevenLabs հաշվի քվոտան։
